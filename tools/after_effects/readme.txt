ART AFTER EFFECTS SCRIPTS V1.0
================================

INSTALL
-------
1. Copy both .jsx files to:
   Adobe After Effects <version>/Support Files/Scripts/
2. Restart After Effects.
3. Run them from File > Scripts.

They are regular floating scripts, not dockable ScriptUI panels. You can also use
File > Scripts > Run Script File without installing them.

Enable "Allow Scripts to Write Files and Access Network" in
Preferences > Scripting & Expressions when file access is blocked.

ART TAKE IMPORTER
-----------------
Select an ART take JSON to import TGA/video/OpenEXR footage, optional keying and
ObjectID mattes, CAM/BVH cameras, and lightweight or full AGR nulls.

ART CAMERA BAKER
----------------
Select one time-remapped precomp containing the original ART camera, run the
script, choose the camera/range/sampling rate, and click Bake Camera. Source-FPS
sampling is recommended for high-FPS captures.
