CS:S V34 ADVANCED RECORDING TOOLS V1.0
======================================

ART is an offline demo-recording tool for Counter-Strike: Source v34 build 4044.

INSTALL
-------
1. Keep v34_art_v1.0.exe and v34_art_v1.0.dll together.
2. Start CS:S and wait for the main menu or a demo.
3. Run v34_art_v1.0.exe.
4. Press Shift+F3 to open ART.

QUICK START
-----------
host_framerate 300
art_record viewmodel on
art_record depth on
art_start shot01
art_stop

Default captures are written under cstrike/art. Run art_help in the game console
for the command summary.

AFTER EFFECTS
-------------
The Scripts folder contains ART Take Importer and ART Camera Baker. Copy both
.jsx files to Adobe After Effects <version>/Support Files/Scripts, restart After
Effects, and run them from File > Scripts. See Scripts/readme.txt.
